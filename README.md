# Responsive Blog Project

A modern and fully responsive blog website built using HTML, CSS, and JavaScript. The project focuses on clean UI design, responsive layouts, and an engaging reading experience across all devices.

---

# Features

- Fully Responsive Design
- Modern Blog UI
- Mobile-Friendly Layout
- Clean and Minimal Interface
- Responsive Navigation Bar
- Blog Cards Layout
- Smooth User Experience
- Cross-Browser Compatibility

---

# Tech Stack

- HTML5
- CSS3
- JavaScript
